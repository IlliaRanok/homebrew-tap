# Ranok Homebrew Tap

Official Homebrew Tap for Media Downloader by Ranok.

## Installation

Add this tap and install Media Downloader:

```bash
brew install illiaranok/tap/media-downloader
```

Or tap first and then install:

```bash
brew tap illiaranok/tap
brew install --cask media-downloader
```

## Update

```bash
brew upgrade media-downloader
```

## Uninstall

```bash
brew uninstall --cask media-downloader
```
